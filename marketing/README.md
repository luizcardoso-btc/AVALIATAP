# Marketing NexTap

Scripts de conteúdo usados pela skill `carrossel-novelinha-nextap`:

- `scripts/render_carousel.py roteiro.json saida [--zip]`: carrossel "novelinha" 1080×1350 (capa, capítulos com gancho, CTA).
- `scripts/mockup_prospect.py --empresa "Nome" [--nota 4.1 --avaliacoes 23] --saida previa.png`: prévia grátis da placa com o nome da empresa + mensagem de abordagem (`previa.txt`).

Dependências: `pip install pillow segno`. Fontes: Poppins (cai para DejaVu se não houver).
`SKILL-carrossel-novelinha.md` é a cópia do texto da skill.
Este diretório não é carregado pelo servidor da NexTap.
